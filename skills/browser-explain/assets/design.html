쿠폰 적용 구조와 실행 흐름

C4 구조도는 시스템 경계에서 프로세스와 내부 책임으로 확대하고, 시퀀스 다이어그램은 요청과 응답을 시간순으로 보여 준다. 각 구성요소의 책임과 실제 실행 경로를 연결해 보기 위해 함께 썼다.

파란 상자는 핵심 구성, 회색 상자는 외부 시스템을 뜻한다.

1. 시스템 경계: 쿠폰 적용은 어디까지인가

고객은 상점에서 쿠폰을 입력하고, 상점은 쿠폰 서비스를 이용해 유효성을 확인합니다.

2. 실행 구조: 무엇이 실행되고 어디에 저장되는가

웹 화면은 서버에 쿠폰 적용을 요청하고 서버는 결과를 주문 저장소에 반영합니다.

3. 컴포넌트: 구성요소와 각자의 책임

쿠폰 처리기는 유효성을 확인하고 할인 결과를 저장합니다.

4. 시퀀스: 쿠폰을 확인하고 할인을 적용한다

상점 서버가 쿠폰 서비스에 유효성을 확인하고 결과를 받습니다.

5. 시퀀스 확대: 유효하지 않은 쿠폰

쿠폰이 유효하지 않으면 상점 서버가 오류 결과를 반환합니다.
