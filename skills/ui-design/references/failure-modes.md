# 화면 디자인의 anti-pattern

이름을 붙여 두면 비교판과 화면 확인 때 "이건 ○○다"라고 짚을 수 있다(Stageshow의 방식). 실제로 겪은 것만 적고, 겪을 때마다 더한다.

| 이름 | 모양 | 고치는 쪽 |
|---|---|---|
| 핵심이 작다 | 화면에서 가장 큰 글자가 그 화면의 핵심이 아니다 | 페이지 핵심을 먼저 정하고 가장 큰 단계를 거기에 |
| 경고 남발 | 경고색이 화면을 차지해 아무것도 경고가 아니다 | 경고색은 작은 점과 짧은 문구에만 |
| 차이 없는 후보 | 후보끼리 거의 같아 고를 것이 없다 | 이론별로 확실히 다른 후보를 만든다 |
| 아무도 안 고른 값 | 에이전트가 빈칸을 기본값으로 채웠다 | 값마다 목적과 원칙을 붙이고, 못 붙이면 고르게 한다 |
| 원 단위 그대로 | 좁은 칸에 정밀한 값을 다 넣어 읽히지 않는다 | 그 화면의 목적에 맞는 단위로, 정확한 값은 다른 화면에 |
