# 허더

## 말뜻과 공식 사용 지침

한글·영어 표기나 발음이 다르게 전사돼도 앞선 대화와 요청 문맥에서 HERDR를 가리키면 HERDR CLI를 사용하라는 뜻으로 이해한다. 정해진 별칭 목록에 한정하지 않는다. 뜻이 분명하면 철자를 다시 확인하지 않고, 다른 의미와 실제로 구분되지 않을 때만 묻는다. HERDR와 무관한 일반 단어나 세션 요청에는 적용하지 않는다.

`HERDR_ENV=1`인지 확인하고, `herdr --skill`로 설치된 공식 에이전트 지침을 읽어 따른다. 현재 명령의 구체적인 사용법은 해당 명령의 `--help`로 확인한다. 인수 없이 `herdr`를 실행하면 대화형 화면이 열리므로 조사에 쓰지 않는다.

## 위치로 대상 찾기

`herdr pane current --current`와 `herdr pane list`로 호출자와 패널 목록을 확인한다. 이후 실제 응답의 패널 ID를 사용한다.

- ‘왼쪽 위’, ‘오른쪽 아래’는 `herdr pane layout --pane <ID>`의 실제 배치 좌표로 찾는다. `x`는 오른쪽으로, `y`는 아래로 증가한다. 패널 수나 시계 방향 번호, 목록 순서를 고정 규칙으로 삼지 않는다.
- ‘네 왼쪽’, ‘네 아래’는 대화 중인 에이전트의 패널을 기준으로 `herdr pane neighbor --pane <ID> --direction left`처럼 이웃을 찾는다. 방향은 `left/right/up/down` 중 고른다.
- 사용자가 선택한 패널(`focused`)을 에이전트 자신의 패널로 가정하지 않는다. 호출자 조회가 실패하면 제목·작업 경로와 필요한 최근 출력을 대화 내용과 대조한다. 자신을 확실히 식별하지 못했고 상대 위치의 기준이 필요하면 묻는다.
- ‘다른 패널’, ‘옆’, ‘저 세션’은 앞선 대화로 특정되면 그 대상을 찾는다. 후보가 여럿이면 위치와 제목을 짧게 제시해 확인한다. 같은 분할 화면을 가리키는 ‘세션’은 패널로 이해한다.
- 별도 HERDR 세션을 뜻하면 `herdr session list`로 실행 중인 이름을 찾는다. 이후 조회와 조작 모두 `herdr --session <이름> ...`으로 같은 범위를 유지한다. 작업 공간·탭이 다르면 해당 범위의 배치를 확인한다. 세션이 다르면 같은 패널 ID가 있을 수 있다.

대상 세션·탭이 달라지거나 패널 배치가 바뀌면 다시 조회한다.

## 요청한 행동 수행

‘봐봐’, ‘확인해’는 내용을 읽고 설명하라는 요청이다. `herdr pane read <ID> --source recent-unwrapped --lines 80`처럼 읽고, 부족하면 필요한 만큼 더 확인한다. 읽지 못한 대화는 추측하지 않는다.

‘저쪽에 이 내용 전달해’처럼 입력·전달·실행을 요청하면 대상과 현재 상태를 확인하고 공식 지침의 해당 명령으로 수행한다. 읽기 요청을 다른 에이전트에게 메시지를 보내거나 일을 맡기는 권한으로 확대하지 않는다. 단순 조회를 위해 사용자의 포커스를 옮기지 않는다.

설정을 물으면 설치된 기본 설정과 실제 설정을 확인한다. 설정 변경은 사용자가 요청한 범위에서 수행하고, 저장·재적용 결과와 실제 화면 확인 여부를 구분해 보고한다.
